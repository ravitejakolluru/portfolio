# Raviteja Kolluru — Portfolio

Premium responsive React + Vite portfolio for software-engineering placements and internships.

## Stack
- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Resume
Place the final resume PDF at:
`public/Raviteja_Kolluru_Resume.pdf`

## Certificate links
The "View Certificate" buttons are intentionally ready to be connected to certificate files/URLs later.

## Project links
Replace the placeholder project/GitHub buttons in `src/App.jsx` with the final repository and live-demo URLs.
